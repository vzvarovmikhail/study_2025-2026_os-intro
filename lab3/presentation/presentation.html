Создание Makefile

FILES = $(patsubst %.md,%.docx,$(wildcard *.md))
FILES += $(patsubst %.md,%.pdf,$(wildcard *.md))

%.docx: %.md
    pandoc $< -o $@

%.pdf: %.md
    pandoc $< -o $@

all: $(FILES)

Makefile автоматизирует сборку документов.

Установка Pandoc

sudo dnf install -y pandoc

Для сборки отчёта использовалась команда:

make

Контрольные вопросы

1. Что такое Markdown? Markdown — легковесный язык разметки, который легко конвертируется в другие форматы.

2. Для чего используется Pandoc? Для преобразования документов между Markdown, PDF, DOCX, HTML, LaTeX и другими форматами.

3. Какие элементы Markdown использованы? Заголовки, форматирование текста, списки, код, ссылки, изображения, таблицы, цитаты и разделители.

4. Что такое Makefile? Файл инструкций для ‘make’, автоматизирующий повторяющиеся операции, в данной работе — сборку PDF и DOCX.

5. В каких форматах получен отчёт? Markdown (‘.md’), PDF (‘.pdf’) и DOCX (‘.docx’).
