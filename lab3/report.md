#### 3. Создание Makefile

Был создан Makefile для автоматической сборки отчёта:

'''makefile
FILES = $(patsubst %.md,%.docx,$(wildcard *.md))
FILES += $(patsubst %.md,%.pdf,$(wildcard *.md))

%.docx: %.md
pandoc $< -o $@

%.pdf: %.md
pandoc $< -o $@

all: $(FILES)

clean:
 rm -f $(FILES) *~

Makefile позволяет одной командой make создавать PDF и DOCX версии отчёта.

### Домашнее задание (Ответы на вопросы)

---

#### 1. Что такое Markdown?

**Ответ:** Markdown — это легковесный язык разметки, созданный для написания текстов в простом формате, который легко конвертируется в HTML, PDF и другие форматы. Он широко используется для оформления документации, отчётов и статей.


---

#### 2. Для чего используется pandoc?

**Ответ:** pandoc — это универсальный конвертер документов. Он позволяет преобразовывать файлы из одного формата в другой: из Markdown в PDF, DOCX, HTML, LaTeX, EPUB и многие другие форматы.

---

#### 3. Какие элементы Markdown использованы в отчёте?

**Ответ:** В отчёте использованы следующие элементы Markdown:

| Элемент | Пример |
|---------|--------|
| Заголовки | '# Заголовок 1', '## Заголовок 2' |
| Полужирный текст | '**текст**' |
| Курсив | '*текст*' |
| Маркированный список | '- элемент' |
| Нумерованный список | '1. элемент' |
| Вложенные списки | отступы для подэлементов |
| Блоки кода | ' '''bash ... ''' ' |
| Встроенный код | '' 'команда' ' |
| Ссылки | '[текст](url)' |
| Изображения | '![подпись](image.png)' |
| Таблицы | '\| столбец1 \| столбец2 \|' |
| Цитаты | '> текст' |
| Горизонтальные разделители | '---' |


---

#### 4. Что такое Makefile и для чего он нужен?

**Ответ:** Makefile — это файл, содержащий инструкции для утилиты 'make'. Он позволяет автоматизировать процесс сборки проекта, включая конвертацию документов, компиляцию программ и другие повторяющиеся задачи.

**Преимущества Makefile:**
- Автоматизация повторяющихся задач
- Экономия времени
- Минимизация ошибок при ручном вводе команд

---


#### 5. В каких форматах получен отчёт?

**Ответ:** Отчёт получен в трёх форматах:

| Формат | Расширение | Назначение |
|--------|------------|------------|
| Markdown | '.md' | Исходный код, редактирование |
| PDF | '.pdf' | Печать, сдача, архивация |
| DOCX | '.docx' | Редактирование в Microsoft Word |
