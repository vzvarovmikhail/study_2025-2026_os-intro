### 3. Синхронизация процессов с помощью семафора

Был создан командный файл `semaphore.sh`, демонстрирующий синхронизацию нескольких процессов при доступе к общему ресурсу.

В качестве семафора используется lock-файл `/tmp/semaphore.lock`. Для атомарного создания файла применяется режим `noclobber`. Если файл успешно создан, процесс получает доступ к ресурсу, использует его заданное время и затем удаляет lock-файл. Если файл уже существует, другой процесс ожидает и повторяет попытку.

## Ответы на контрольные вопросы

1. **Что представляет собой командный файл?**  
   Командный файл — это текстовый файл, содержащий последовательность команд оболочки, которые выполняются интерпретатором команд.

2. **Для чего используется переменная RANDOM в Bash?**  
   Переменная `RANDOM` возвращает псевдослучайное целое число и может применяться для генерации случайных значений и последовательностей.

3. **Для чего используются функции в Bash?**  
   Функции позволяют объединять повторяющиеся действия в именованный блок команд, который можно вызывать многократно.

4. **Что такое семафор?**  
   Семафор — механизм синхронизации, используемый для управления доступом нескольких процессов к общему ресурсу.

5. **Для чего нужен lock-файл?**  
   Lock-файл служит признаком того, что ресурс в данный момент занят одним из процессов.

6. **Как работает цикл while?**  
   Цикл `while` выполняет набор команд до тех пор, пока проверяемое условие возвращает истинный код завершения.

7. **Что делает команда sleep?**  
   Команда `sleep` приостанавливает выполнение процесса на указанное количество времени.
