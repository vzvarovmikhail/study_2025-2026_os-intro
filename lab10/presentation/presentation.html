Основные режимы vi

Редактор vi имеет три основных режима:

  • командный режим;
  • режим вставки;
  • режим последней строки.

Командный режим используется для управления текстом и перемещения.

Режим вставки предназначен для ввода текста.

Режим последней строки используется для сохранения, выхода, поиска, замены и настройки редактора.

Основные команды vi

Для перехода в режим вставки используются:

i
a
o

Для возврата в командный режим:

Esc

Сохранение и выход:

:wq

Выход без сохранения:

:q!

Удаление строки:

dd

Отмена последнего действия:

u

Наличие символа x показывает, что файл является исполняемым.

Работа в редакторе vi

Файл был повторно открыт:

Для отображения номеров строк использовалась команда:

При редактировании были использованы командный режим, режим вставки и режим последней строки.
