### 4.2. Изменение прав доступа с помощью chmod

## 6. Определение команд chmod

Для файлов с указанными правами доступа необходимо подобрать команду 'chmod':

### 6.1. `drwxr--r-- ... australia`

**Решение:** Владелец имеет полные права ('rwx'), группа — только чтение ('r--'), остальные — только чтение ('r--').

'''bash
chmod 744 australia
### 6.2. drwx--x--x ... play

Решение: Владелец имеет полные права (rwx), группа — только выполнение (--x), остальные — только выполнение (--x).
bash

chmod 711 play

---

### 6.3. -r-xr--r-- ... my_os

Решение: Владелец имеет права на чтение и выполнение (r-x), группа — только чтение (r--), остальные — только чтение (r--).
bash

chmod 544 my_os

### 6.4. -rw-rw-r-- ... feathers

Решение: Владелец имеет права на чтение и запись (rw-), группа — чтение и запись (rw-), остальные — только чтение (r--).
bash

chmod 664 feathers

## 7. Контрольные вопросы

### 7.1. Какие команды используются для создания файлов?

**Ответ:** Основные команды для создания файлов:
- 'touch имя_файла` — создание пустого файла
- 'cat > имя_файла` — создание файла с вводом текста с клавиатуры
- 'nano имя_файла` — создание файла в текстовом редакторе nano
- 'echo "текст" > имя_файла` — создание файла с заданным содержимым

---

### 7.2. Как просмотреть содержимое файла?

**Ответ:**
- 'cat имя_файла` — вывод всего содержимого файла на экран
- 'less имя_файла` — постраничный просмотр файла
- 'head [-n] имя_файла` — вывод первых строк (по умолчанию 10)
- 'tail [-n] имя_файла` — вывод последних строк (по умолчанию 10)

---

### 7.3. Как скопировать файл в другой каталог?

**Ответ:**
'''bash
cp файл каталог/
**Пример:**

### 7.4. Как рекурсивно скопировать каталог?

**Ответ:**

'''bash
cp -r каталог_источник каталог_назначение

### 7.5. Как переименовать файл?

**Ответ:**

**Пример:**

### 7.6. Как переместить файл в другой каталог?

## 7.7. Как изменить права доступа?

**Отвеt:**
bash

chmod [опции] права файл

**Способы:**

   Символьный: chmod u+x файл

   Цифровой: chmod 755 файл
### 7.8. Какие основные возможности команды mv?

**Ответ:**

- Переименование файлов
- Перемещение файлов между каталогами
- Переименование каталогов
- Перемещение каталогов

---

### 7.9. Что такое права доступа?

**Ответ:** Права доступа определяют, кто и какие действия может выполнять с файлом или каталогом.

**Типы прав:**

- 'r` (read) — чтение
- 'w` (write) — запись
- `x' (execute) — выполнение

**Категории пользователей:**

- `u' (user) — владелец файла
- `g' (group) — группа владельца
- `o' (others) — все остальные
