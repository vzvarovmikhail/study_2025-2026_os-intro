Перенаправление вывода

ls /etc > file.txt
ls ~ >> file.txt

Операторы:

  • ‘>’ — перезаписывает файл;
  • ‘>>’ — добавляет данные в конец;
  • ‘2>’ — перенаправляет поток ошибок.

Фильтрация данных

grep "\.conf" file.txt
grep "\.conf" file.txt > conf.txt

‘grep’ использовался для поиска строк по заданному шаблону.

Поиск файлов

find ~ -maxdepth 1 -name "c*" -type f 2>/dev/null
find /etc -maxdepth 1 -name "h*" -type f 2>/dev/null

Команда ‘find’ позволяет выполнять поиск по имени и типу объекта.

Фоновые процессы

find /var/log -name "log*" -type f \
  2>/dev/null > ~/logfile &

jobs

Символ ‘&’ запускает команду в фоновом режиме.

Использование диска

df -h
du -sh ~/
  • ‘df’ показывает использование файловых систем.
  • ‘du’ показывает объём, занимаемый файлами и каталогами.

Поиск каталогов

find ~ -type d 2>/dev/null
find ~ -maxdepth 1 -type d 2>/dev/null

Опция ‘-type d’ ограничивает поиск каталогами.

Контрольные вопросы

1. Какие стандартные потоки существуют? ‘stdin (0)’ — ввод, ‘stdout (1)’ — вывод, ‘stderr (2)’ — ошибки.

2. Чем ‘>’ отличается от ‘>>’? ‘>’ перезаписывает файл, ‘>>’ добавляет данные в конец.

3. Что такое конвейер? Конвейер ‘|’ передаёт вывод одной команды на ввод другой.

4. Для чего используются ‘find’ и ‘grep’? ‘find’ ищет файлы и каталоги по критериям, ‘grep’ фильтрует текст по шаблону.

5. Для чего нужны ‘df’ и ‘du’? ‘df’ показывает использование файловых систем, ‘du’ — размер файлов и каталогов.
