### Домашнее задание (Ответы на контрольные вопросы)

#### 1. Какие потоки ввода-вывода вы знаете?

**Ответ:** В системе существует три стандартных потока:

| Поток | Описание | Файловый дескриптор |
|-------|----------|---------------------|
| 'stdin` | Стандартный ввод (по умолчанию — клавиатура) | 0 |
| 'stdout` | Стандартный вывод (по умолчанию — консоль) | 1 |
| 'stderr` | Стандартный вывод ошибок (по умолчанию — консоль) | 2 |

---

#### 2. Объясните разницу между операцией `>` и `>>`.

**Ответ:**
- '>` — перенаправляет вывод в файл, **перезаписывая** его содержимое (если файл существует, он будет заменён).
- '>>` — перенаправляет вывод в файл, **добавляя** новые данные в конец файла (существующее содержимое сохраняется).

**Примеры:**
'''bash
echo "Новый текст" > file.txt   # файл перезаписан
echo "Дополнительный текст" >> file.txt   # добавлено в конец

#### 3. Что такое конвейер?

**Ответ:** Конвейер ('|') — это механизм в командной оболочке, позволяющий передавать вывод (stdout) одной команды на ввод (stdin) другой команды. Это позволяет строить цепочки команд для обработки данных без создания промежуточных файлов.

**Пример:**
'''bash
ls -la | grep ".conf" | sort
В этом примере:

   ls -la выводит список файлов;

   grep ".conf" фильтрует строки, содержащие .conf;

   sort сортирует полученный список.

Конвейеры можно объединять в длинные цепочки для комплексной обработки данных:
bash

ps aux | grep "python" | awk '{print $2}' | xargs kill -9

Эта команда находит все процессы Python, извлекает их PID и завершает их.

#### 5. Что такое PID и GID?

**Ответ:**

- **PID** (Process IDentifier) — это уникальный числовой идентификатор, который присваивается каждому процессу в момент его создания. PID используется системой и пользователем для управления процессами (например, для завершения процесса через команду `kill`).

- **GID** (Group IDentifier) — это идентификатор группы процессов. В контексте управления заданиями GID позволяет обращаться к группе процессов, связанных общей задачей. При запуске процесса он получает тот же GID, что и родительский процесс.

**Пример использования:**

'''bash
ps aux | grep gedit
Вывод может содержать:
text

user   1234  0.0  0.5  ...  gedit

Здесь 1234 — это PID процесса gedit.

Для завершения процесса используется команда:
bash

kill 1234

При работе с фоновыми задачами (jobs) используется идентификатор задачи (job ID), который обозначается как %номер:
bash

kill %1
Отличие PID от job ID:
Идентификатор	Описание
PID	Глобальный идентификатор процесса во всей системе
Job ID	Локальный идентификатор задачи в текущем сеансе терминала (обозначается %номер)
Пример просмотра задач:
bash

jobs

Вывод:
text

[1]  + running    gedit &

Здесь [1] — это job ID, а сам процесс имеет свой PID, который можно узнать через ps.

#### 7. Найдите информацию об утилитах `top` и `htop`. Каковы их функции?

**Ответ:**

**'top'** — это встроенная интерактивная утилита для мониторинга системных процессов и ресурсов в реальном времени. Она показывает:

- Загрузку CPU (по ядрам и в целом);
- Использование оперативной памяти (RAM) и swap;
- Список запущенных процессов с их PID, состоянием, приоритетом, потреблением ресурсов;
- Общую информацию о системе (время работы, количество пользователей, нагрузку).

**'htop'** — это улучшенная версия 'top' с более удобным интерфейсом. Основные отличия:

| Функция | 'top' | 'htop' |
|---------|-------|--------|
| Интерфейс | Текстовый, монохромный | Цветной, с прокруткой |
| Управление | Только клавиатура (k, r, q и др.) | Клавиатура + поддержка мыши |
| Прокрутка | Нет | Да (можно прокручивать список процессов) |
| Завершение процессов | Требуется ввод PID | Можно выбрать процесс и нажать F9 |
| Дерево процессов | Нет | Да (F5) |
| Настройка | Через конфигурационный файл | Интерактивная настройка (F2) |

**Пример запуска:**

'''bash
top

#### 9. Можно ли по контексту (содержанию) найти файл? Если да, то как?

**Ответ:** Да, можно. Для поиска файлов по их содержимому используется команда 'grep' с опцией рекурсивного поиска '-r' (или '-R'). Это позволяет искать указанную строку или шаблон во всех файлах внутри каталога и его подкаталогов.

**Основные опции 'grep' для поиска по содержимому:**

| Опция | Описание |
|-------|----------|
| '-r' или '-R' | Рекурсивный поиск по всем файлам в каталогах |
| '-i' | Игнорировать регистр (поиск без учёта заглавных/строчных букв) |
| `-l' | Вывести только имена файлов, содержащих совпадение |
| `-n' | Показать номера строк, где найдено совпадение |
| `-w' | Искать целые слова |
| '--include=*.txt` | Искать только в файлах с указанным расширением |
| '--exclude=*.log` | Исключить файлы с указанным расширением |

**Примеры использования:**

1. **Поиск слова "error" во всех файлах в домашнем каталоге:**
'''bash
grep -r "error" ~/
   Поиск с игнорированием регистра:

bash

grep -ri "error" ~/

   Вывод только имён файлов, содержащих слово "pattern":

bash

grep -rl "pattern" ~/

   Поиск только в файлах с расширением .log:

bash

grep -r --include=*.log "error" /var/log/

   Поиск с выводом номеров строк:

bash

grep -rn "error" ~/

   Поиск целого слова (не части слова):

bash

grep -rw "error" ~/

   Поиск в текущем каталоге, исключая файлы .log:

bash

grep -r --exclude=*.log "error" ./

Комбинация с другими командами:
bash

find ~ -name "*.txt" -exec grep "pattern" {} \;

#### 10. Как определить объём свободной памяти на жёстком диске?

**Ответ:** Для определения объёма свободного места на жёстком диске используется команда 'df' (disk free). Она показывает информацию о всех смонтированных файловых системах: размер, использованное и свободное пространство, процент заполнения и точку монтирования.

**Синтаксис:**
'''bash
df [опции]

#### 11. Как определить объём вашего домашнего каталога?

**Ответ:** Для определения размера домашнего каталога используется команда 'du' (disk usage). Она показывает, сколько дискового пространства занимают файлы и каталоги.

**Синтаксис:**
'''bash
du [опции] [путь]
