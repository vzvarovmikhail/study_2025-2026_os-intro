# Цель работы

Изучить основы программирования в оболочке ОС UNIX/Linux.

Научиться писать более сложные командные файлы с использованием логических управляющих конструкций и циклов.

---

# Задания

1. Обработать параметры командной строки с помощью getopts и выполнить поиск через grep.
2. Передать информацию из программы на C через код завершения.
3. Создать и удалить заданное количество временных файлов.
4. Архивировать недавно изменённые файлы с помощью find и tar.

---
