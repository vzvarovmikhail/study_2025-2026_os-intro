# Запуск Midnight Commander

    mc

Основные операции с панелями:

-   'Tab' — переключение;
-   'Ctrl+u' — поменять панели местами;
-   'Ctrl+o' — скрыть панели;
-   'Ctrl+x d' — сравнить каталоги.

---

# Функциональные клавиши

  Клавиша   Действие
  ——— ——————-
  F3        Просмотр

  F6        Перемещение
  F7        Создание каталога
  F8        Удаление

  F10       Выход

# Встроенный редактор

Основные команды:

-   'F2' — сохранить;
-   'F10' — выйти;
-   'Ctrl+y' — удалить строку;
-   'Ctrl+u' — отменить действие;
-   'Ctrl+k' — копировать строку;
-   'Alt+<' / 'Alt+>' — начало / конец файла.

# Контрольные вопросы

**1. Какие режимы работы есть в Midnight Commander?**
Стандартный, информация и дерево каталогов.

**2. Какие операции с файлами можно выполнять?**
Копирование ('F5'), перемещение ('F6'), создание каталогов ('F7'),
удаление ('F8'), просмотр ('F3'), редактирование ('F4').

**3. Что содержит меню «Файл»?**
Права доступа, владелец/группа, ссылка, просмотр и редактирование.

**4. Какие основные команды встроенного редактора?**
'F2' — сохранить, 'F10' — выйти, 'Ctrl+y' — удалить строку,
'Ctrl+u' — отменить действие.

**5. Как создать собственное меню?**
Через «Команда → Редактировать файл меню».
