# Лабораторная работа №9
## Командная оболочка Midnight Commander

---

### Цель работы

Освоение основных возможностей командной оболочки Midnight Commander. Приобретение навыков практической работы по просмотру каталогов и файлов, манипуляций с ними.

---

### Задание

1. Изучить интерфейс Midnight Commander.
2. Освоить операции с панелями (переключение, смена мест, отключение, режимы).
3. Выполнить операции с файлами (копирование, перемещение, удаление, создание каталогов).
4. Изучить меню: Файл, Команда, Настройки.
5. Создать и отредактировать текстовый файл во встроенном редакторе.
6. Выполнить поиск файлов.

#### 1. Запуск Midnight Commander

#### 2. Панели и их управление

**Основные операции с панелями:**

| Действие | Клавиши |
|----------|---------|
| Переключение между панелями | Tab |
| Смена панелей местами | Ctrl+u |
| Отключение панелей | Ctrl+o |
| Сравнение каталогов | Ctrl+x d |

**Режимы панелей:**

- **Стандартный** — отображение списка файлов
- **Информация** — сведения о текущем файле и файловой системе
- **Дерево** — структура дерева каталогов

---

#### 3. Операции с файлами

**Функциональные клавиши:**

| Клавиша | Действие |
|---------|----------|
| F1 | Справка |
| F3 | Просмотр файла |
| F4 | Редактирование файла |
| F5 | Копирование файла |
| F6 | Перемещение файла |
| F7 | Создание каталога |
| F8 | Удаление файла |
| F9 | Меню |
| F10 | Выход |

**Операции, выполненные в ходе работы:**

1. **Создание каталога** — F7 → 'test_dir'
2. **Создание файла** — через терминал командой 'touch text.txt', затем открытие через F4
3. **Копирование файла** — F5 → 'copy.txt'
4. **Перемещение файла** — F6 → 'test_dir/'
5. **Просмотр файла** — F3
6. **Изменение прав доступа** — F9 → Файл → Права доступа → chmod +x
7. **Удаление файла** — F8


---

#### 4. Меню Midnight Commander

**Меню Левая/Правая панель:**
- Формат списка
- Сортировка
- Информация
- Дерево

**Меню Файл:**
- Права доступа (chmod)
- Владелец/группа (chown)
- Ссылка (ln)
- Просмотр (F3)
- Редактирование (F4)

**Меню Команда:**
- Переставить панели (Ctrl+u)
- Сравнить каталоги (Ctrl+x d)
- История командной строки
- Найти файл
- Каталоги быстрого доступа (Ctrl+\)

**Меню Настройки:**
- Конфигурация
- Внешний вид
- Расцветка имён

---

#### 5. Встроенный редактор mc

**Основные команды редактора:**

| Действие | Клавиши |
|----------|---------|
| Сохранить файл | F2 |
| Выйти из редактора | F10 |
| Удалить строку | Ctrl+y |
| Отменить действие | Ctrl+u |
| Копировать строку | Ctrl+k |
| Выделить текст | Shift+стрелки |
| Копировать выделенное | F5 → Enter |
| Вставить | Переместить курсор → F5 → Enter |
| Переместить выделенное | F6 → Enter |
| Переход в начало файла | Alt+< |
| Переход в конец файла | Alt+> |

**Работа в редакторе:**

1. Создание файла: 'touch text.txt' в терминале
2. Открытие файла в mc: выделить → F4
3. Ввод текста
4. Сохранение: F2 → Enter
5. Выход: F10

#### 6. Поиск файлов

### Домашнее задание (Ответы на вопросы)

#### 1. Какие режимы работы есть в mc?

**Ответ:** В Midnight Commander существуют три основных режима отображения панелей:
- **Стандартный** — отображение списка файлов с их атрибутами
- **Информация** — отображение подробной информации о текущем файле и файловой системе
- **Дерево** — отображение структуры каталогов в виде дерева

#### 2. Какие операции с файлами можно выполнить в mc?

**Ответ:** В mc можно выполнять следующие операции с файлами:
- Копирование (F5)
- Перемещение (F6)
- Создание каталогов (F7)
- Удаление (F8)
- Просмотр (F3)
- Редактирование (F4)
- Изменение прав доступа (chmod)
- Изменение владельца (chown)
- Создание ссылок (ln)

- Информация
- Дерево

#### 4. Структура меню Файл?

- Ссылка
- Просмотр

#### 7. Встроенные команды mc?

**Ответ:** Встроенные команды mc — это команды, выполняемые через командную строку mc (Alt+Enter). Они позволяют выполнять shell-команды без выхода из mc.

#### 8. Команды встроенного редактора mc?

**Ответ:** Основные команды встроенного редактора mc:
- F2 — сохранить файл
- F10 — выйти из редактора
- Ctrl+y — удалить строку
- Ctrl+u — отменить действие
- Ctrl+k — копировать строку
- Shift+стрелки — выделение текста
- F5 → Enter — скопировать выделенное
- F6 → Enter — переместить выделенное
- Alt+< — в начало файла
- Alt+> — в конец файла


---

#### 9. Создание меню пользователем?

**Ответ:** Пользователь может создавать собственное меню через редактирование файла меню (меню Команда → Редактировать файл меню). Это позволяет добавить пользовательские пункты меню для автоматизации часто выполняемых задач.

#### 10. Выполнение действий над файлом?

**Ответ:** Действия над файлом выполняются через меню Файл или с помощью функциональных клавиш:
- Просмотр — F3
- Редактирование — F4
- Копирование — F5
- Перемещение — F6
- Удаление — F8
- Изменение прав — F9 → Файл → Права доступа
