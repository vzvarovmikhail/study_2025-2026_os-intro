# Контрольные вопросы

## 1. Что такое командный процессор? Приведите примеры. Чем они отличаются?

Командный процессор, или shell, — это программа, обеспечивающая взаимодействие пользователя с операционной системой посредством команд. Он принимает команды пользователя, интерпретирует их и организует выполнение соответствующих программ. Примерами являются `sh`, `csh`, `ksh` и `bash`. Они отличаются синтаксисом, набором встроенных команд, средствами программирования и дополнительными возможностями интерактивной работы.

## 2. Что такое POSIX?

POSIX (Portable Operating System Interface) — это семейство стандартов, определяющих унифицированный интерфейс операционных систем UNIX-подобного типа. Стандартизация позволяет создавать программы и командные файлы, которые легче переносить между различными совместимыми системами.

## 3. Как определяются переменные и массивы в Bash?

Переменная задаётся присваиванием без пробелов около знака равенства:

    name=value

Обращение к значению выполняется с помощью символа `$`:

    echo $name

Массив можно определить, например, следующим образом:

    array=(one two three)

Для обращения к элементу массива используется конструкция:

    ${array[0]}

## 4. Для чего предназначены команды let и read?

Команда `let` используется для выполнения целочисленных арифметических операций и изменения значений переменных. Команда `read` считывает данные из стандартного ввода и сохраняет их в переменных командного процессора.

Пример:

    read number
    let number=number+1

## 5. Какие арифметические операции можно выполнять в Bash?

Bash поддерживает сложение, вычитание, умножение, деление, получение остатка от деления, возведение в степень, инкремент и декремент, а также операции сравнения и присваивания.

Например:

    result=$((a + b))
    result=$((a * b))
    result=$((a % b))

## 6. Что означает конструкция (( ))?

Конструкция `(( ))` используется для вычисления арифметических выражений в Bash. Внутри неё можно выполнять вычисления, изменять переменные и использовать арифметические сравнения.

Например:

    ((count++))
    ((result = a + b))

## 7. Какие стандартные имена переменных используются в Bash?

В командном процессоре используются различные стандартные переменные окружения и shell-переменные. Например, `HOME` содержит путь к домашнему каталогу пользователя, `PATH` — список каталогов поиска исполняемых программ, `USER` — имя пользователя, `PWD` — текущий рабочий каталог, `SHELL` — используемый командный процессор.

## 8. Что такое метасимволы?

Метасимволы — это символы, имеющие специальное значение для командного процессора. К ним относятся, например, `*`, `?`, `$`, `&`, `|`, `;`, `<`, `>`, круглые и квадратные скобки. Они применяются для подстановок, перенаправления потоков, построения конвейеров и управления выполнением команд.

## 9. Как экранировать метасимволы?

Для отмены специального значения отдельного символа используется обратная косая черта `\`. Также применяются одинарные и двойные кавычки. Одинарные кавычки подавляют интерпретацию большинства специальных символов, а двойные позволяют выполнять некоторые подстановки, например подстановку переменных.

## 10. Как создать и запустить командный файл?

Необходимо создать текстовый файл, записать в него команды и обычно указать интерпретатор в первой строке:

    #!/bin/bash

После этого файлу можно предоставить право на выполнение:

    chmod +x script.sh

И запустить:

    ./script.sh

Также командный файл можно передать интерпретатору непосредственно:

    bash script.sh

## 11. Как определяются функции в Bash?

Функцию можно определить следующим образом:

    function hello {
        echo "Hello"
    }

или:

    hello() {
        echo "Hello"
    }

После определения функция вызывается по своему имени:

    hello

## 12. Как определить, является объект каталогом или обычным файлом?

Для проверки типа объекта используются условные выражения. Ключ `-d` проверяет, является ли объект каталогом, а `-f` — обычным файлом:

    if [ -d "$name" ]; then
        echo "directory"
    fi

    if [ -f "$name" ]; then
        echo "regular file"
    fi

## 13. Для чего предназначены команды set, typeset и unset?

Команда `set` используется для управления параметрами и режимами работы командного процессора, а также для установки позиционных параметров. `typeset` позволяет объявлять переменные и задавать их свойства. `unset` удаляет ранее определённую переменную или функцию.

## 14. Как передаются параметры в командный файл?

Параметры указываются после имени командного файла при его запуске:

    ./script.sh first second third

Внутри сценария к ним можно обращаться через позиционные параметры `$1`, `$2`, `$3` и т. д. `$0` содержит имя самого командного файла. Для обработки большого количества аргументов удобно использовать `$@`, `$#` и команду `shift`.

## 15. Какие специальные переменные Bash используются и для чего?

К основным специальным параметрам относятся:

- `$0` — имя выполняемого командного файла;
- `$1`, `$2`, ... — позиционные параметры;
- `$#` — количество переданных параметров;
- `$*` — все позиционные параметры;
- `$@` — все позиционные параметры с сохранением их разделения;
- `$?` — код завершения последней команды;
- `$$` — идентификатор текущего процесса shell;
- `$!` — идентификатор последнего процесса, запущенного в фоновом режиме.
