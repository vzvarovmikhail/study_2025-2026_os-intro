# Цель работы

Изучить основы программирования в командном процессоре ОС UNIX/Linux.

Получить практические навыки разработки командных файлов на языке Bash.

---

# Задания

1. Создать скрипт резервного копирования.
2. Обработать произвольное количество аргументов.
3. Реализовать аналог команды ls.
4. Подсчитать файлы заданного типа.

---

# Задание 1

## Резервное копирование

Создан командный файл backup_script.sh.

Скрипт создаёт резервную копию самого себя и помещает архив в каталог ~/backup.
